# MandiarteStudio

AI Photo Processor for WooCommerce Product Photography

This repository contains a small skeleton for the MandiarteStudio project. The commit created placeholder modules and a directory structure for filters, engine, core utilities, UI, profiles, assets and output.

Estructura creada:

- app.py
- core/
- engine/
- filters/
- profiles/
- ui/
- assets/
- output/
- tests/

Cómo usar:

1. Crear un entorno virtual: python -m venv .venv
2. Activar el entorno: source .venv/bin/activate (Linux/Mac) o .venv\Scripts\activate (Windows)
3. Instalar dependencias: pip install -r requirements.txt
4. Ejecutar: python app.py

Este README y los archivos son plantillas iniciales. Rellena la lógica de procesamiento de imágenes y la interfaz según los requerimientos del proyecto.
